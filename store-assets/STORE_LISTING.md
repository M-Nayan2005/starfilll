## Short description (max 132 chars)
One-click rating filler for feedback forms with stars. Fully local. No data collected, no permissions.

## Detailed description
Tired of clicking star after star on long feedback forms? StarFill spots them for you.

• A small button appears automatically only on pages that contain several star-rating fields
• Choose 1–5 stars and press Fill; every rating on the page is set at once
• You review the form and press Submit yourself. StarFill never submits anything
• Does not touch text boxes or multiple-choice questions
• Switched off on shopping, app-store, maps and review sites

PRIVACY FIRST
StarFill collects nothing, stores nothing and sends nothing. It uses no permissions and makes no network requests. Detection happens locally on your device.

Please use it honestly: give genuine ratings where your opinion matters. Not affiliated with any institution or website.

## Single purpose (required field)
Detect star-rating fields on a web page's feedback form and let the user fill them all with one click.

## Host permission justification (required because it runs on all sites)
Feedback forms with star ratings can appear on any website, so the content script must run on web pages to detect them. The script works entirely locally: it does not read, store, or transmit page content, and it makes no network requests. It is disabled on shopping, app-store, maps and review sites.
